Лабораторная работа №2. Текстовый редактор с паттерном Мост.

Назначение: 
отделить абстракцию(что делает этот класс) от ее реализации (как делает что-то этот класс) так, чтобы то и другое можно было  изменять независимо.

Проблема:
1) Появление большого объёма классов.
2) Жёсткая связанность абстракции и реализации.
3) Нет разделения иерархий абстракции и реализации.

Решение:
1) Разделяет иерархии, уменьшая количество классов до суммы (N + M).
2) Ослабляет связь чтобы она стало независимой.
3) Позволяет добавлять новые реализации и новые абстракции независимо, не меняя существующий код.

Как здесь всё происходит на примере “научный текст → DOC статья”

Логика такая:

1)Пользователь вставляет текст в TextEditorUI

2)Выбирает radio button Scientific

3)Нажимает кнопку SetUp

4)Вызывается onSetUpClicked()

GUI создаёт:

1)ScientificText

2)ArticleDocFormat

3)ScientificText.export(filePath) вызывает у форматера экспорт

4)Получается .doc-файл статьи
